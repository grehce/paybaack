# PAYBAACK landing page

Static private-beta landing page for [paybaack.com](https://paybaack.com/).

## Deployment

This repository is configured for GitHub Pages with the custom domain in `CNAME`.
After Pages is enabled from the repository root, point the domain's DNS to GitHub Pages and enable HTTPS.

Before launch, replace `REPLACE-WITH-YOUR-EMAIL@example.com` in `index.html` and `agent.json` with the beta-intake inbox.
