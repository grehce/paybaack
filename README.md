# PAYBAACK landing page

Static private-beta landing page for [paybaack.com](https://paybaack.com/).

## Deployment

This repository is configured for GitHub Pages with the custom domain in `CNAME`.
After Pages is enabled from the repository root, point the domain's DNS to GitHub Pages and enable HTTPS.

Public contact addresses are hello@paybaack.com (general) and disputes@paybaack.com (invoice responses). Both forward to the owner's inbox via Squarespace email forwarding; no personal address appears on the site.

See [CHAT.md](CHAT.md) for Grace, the FAQ chat agent (`faq.json`, `chat/`, `worker/`, `evals/`).
